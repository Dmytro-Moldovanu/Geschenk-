# GitHub-Veröffentlichung (Geschenk?)

Das Repository ist bereits unter https://github.com/Dmytro-Moldovanu/Geschenk- angelegt.

1. ZIP entpacken. **Die Inhalte dieses Projektordners**, nicht den Ordner selbst, in das Stammverzeichnis des GitHub-Repositories hochladen. Wichtig: `README.md`, `index.html`, `package.json`, `docs/` und `screenshots/` müssen sich direkt im Repository befinden.
2. Das Repository ggf. unter Settings > General > Danger Zone > Change repository visibility auf Public stellen. Bei GitHub Free ist Pages nur aus öffentlichen Repositories verfügbar.
3. In Settings > Pages die Veröffentlichung über 'Deploy from a branch', Branch 'main' und Ordner '/docs' aktivieren. Speichern.
4. Den Deployment-Status unter Actions prüfen. Danach die Live-Adresse öffnen: https://dmytro-moldovanu.github.io/Geschenk-/
5. Unter der Repository-Startseite bei 'About' die Beschreibung und die Live-URL eintragen.
